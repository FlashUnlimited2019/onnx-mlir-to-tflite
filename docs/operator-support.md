# ONNX to TFL operator support

This matrix documents configurations validated by deterministic MLIR
regression tests and end-to-end numerical comparisons. Coverage is primarily
for static ranked tensors and includes selected `ai.onnx` operator revisions
from opsets 1 through 24, plus selected `com.microsoft` opset 1 operators. An
opset listed for a row indicates tested compatibility for that operator
revision, not complete support for the entire opset. Only the type, rank, and
attribute configurations stated below are claimed.

The test columns use coverage categories rather than individual test or model
names. MLIR coverage includes direct lowering, importer transformations,
diagnostics, internal forms, and static shape/layout regressions; E2E coverage
includes constructed operator fixtures and representative CNN, vision,
transformer, and sequence workloads.
